# Помощник ИИ - образец RustGIS и помощник модуля

Обзор от 25 октября 2026 года для модуля PlanetX, позже - для переноса
в Lite на Rust (`doc/PLAN.md`, раздел «Будущие задачи»). Код RustGIS
прочитан в хранилище `github.com/opengeos/RustGIS` (Apache 2.0),
описание - https://rustgis.app/user-guide/assistant/. Лицензии
зависимостей названы по памяти, перед решением их сверяет `cargo deny`.

## Помощник RustGIS

Крейт `crates/assistant`, файлы `provider.rs` (форматы запросов),
`agent.rs` (цикл), `tools.rs` (инструменты), `skills.rs`, `mcp.rs`,
`acp.rs`, `chatgpt.rs` (вход ChatGPT, PKCE), `relay.rs`, `audit.rs`.
Навыки - `crates/assistant/skills/*/SKILL.md`, шесть штук. Окно -
`crates/ui-egui/src/assistantpane.rs`.

Главный приём - ядро без ввода-вывода. Запрос и ответ - данные:
- `provider.rs`: `Api { OpenAi, Responses, Anthropic, Gemini }`,
  `PRESETS` на семь провайдеров, `Config` с `Debug` без ключа,
  `HttpRequest`, `HttpResponse`, `ToolDef { name, description, schema }`,
  `Turn`, `Reply`. Функции `chat_request` и `parse_reply`.
- Поток SSE режет `sse_events`, `assembled` собирает поток в обычный
  ответ, разбор один. Поток без признака конца не исполняет инструменты.
  Пределы - 8 МиБ ответа, 64 МиБ потока.
- `retry_delay` повторяет 408, 429, 5xx и 529 с учётом `retry-after`,
  квоту не повторяет. `allowed_url` пускает только HTTPS, HTTP - для
  localhost и частных адресов.
- `agent.rs` - автомат состояний `Step { Send, Confirm, Retry, Done }`.
  Номер `generation` отбрасывает ответы после остановки. Пределы - 16
  запросов на сообщение, 3 повтора. Блок `<map>` с картой идёт только
  при её изменении. Сжатие беседы - сначала обрезка старых ответов
  инструментов, потом сводка моделью.
- `tools.rs`: инструменты исполняются синхронно, каждый вызов - один
  шаг отмены. `gate(call)` даёт причину вопроса Allow / Decline: файлы,
  сеть, аддины, скрипты, замена проекта, SQL. «Разрешить в этой беседе»
  помнит команду с точными параметрами.
- Вывод инструмента - до 10 000 токенов, потолок 24 000, 4 байта
  на токен, остаток с пометкой `"truncated": true`.
- Навыки `SKILL.md`: в подсказку идёт только каталог, текст модель
  берёт через `load_skill`. `mcp.rs` - сервер JSON-RPC без ввода-вывода.
  `acp.rs` - агенты на компьютере, только в настольной программе.

Отправка: в программе поток с `ureq` и `rustls`, ответ в общий слот
и опрос в следующем кадре. На странице - fetch браузера прямо
к провайдеру. Anthropic требует заголовок
`anthropic-dangerous-direct-browser-access: true`, OpenAI, Gemini
и OpenRouter принимают запросы со страницы, Ollama - через
`OLLAMA_ORIGINS`. Ключи в программе - системная связка
(`keyring-core`), на странице - память сессии, localStorage только
по флажку и с предупреждением.

## Помощник модуля

- `core/assistant.py` без Qt: форматы `ANTHROPIC`, `RESPONSES`, `CHAT`,
  подключения anthropic, responses (Grok), deepseek, openrouter
  (по умолчанию `openrouter/free`), local (Ollama). `MAX_ROUNDS = 6`.
  `StreamText` разбирает SSE трёх форматов, `extract_kml` достаёт KML
  из ответа.
- Пятнадцать инструментов: `fly_to`, `search_place`, `set_body`,
  `set_layer`, `set_time`, `earth_cutaway`, `section_down`, `point_info`,
  `quakes_summary`, `add_kml`, `list_actions`, `run_action`,
  `set_opacity`, `add_basemap`, `get_kml`. Исполнитель - `_tool_<имя>`
  в `ui/globe/identify.py`.
- Контекст - `assistant_context()`: вид, тело, включённые слои, разрез,
  выделенные метки, время. Названия слоёв и меток в модель не уходят.
- Одобрение есть у `add_kml` и `add_basemap`, прочие инструменты
  выполняются сразу. Ключи - менеджер паролей QGIS или открытый текст.
- «Объясни это» - `explain_question` в `ui/placecard.py`.

## Что взять у RustGIS

- Ядро без ввода-вывода и автомат `Step`, номер `generation`.
- Контекст только при изменении вида.
- Предел вывода инструмента с пометкой `truncated`.
- `retry_delay`, `allowed_url`, `Debug` без ключа.
- `gate` с причиной для всех действий с файлами, сетью и данными,
  ключ одобрения по точным параметрам.
- Навыки `SKILL.md` с `load_skill` - ложатся на аддины.
- Сервер MCP позже. ACP и вход ChatGPT - в последнюю очередь.

## Перенос в Lite, когда до него дойдёт

- `crates/assistant` без egui, сети и потоков, собирается под wasm32:
  форматы провайдеров, SSE, автомат, схемы инструментов, пределы
  вывода, сжатие, `extract_kml`, контекст. Тесты - из
  `tests/test_assistant.py` модуля, раньше кода.
- В `net` - запрос с потоком ответа: в программе поток с `ureq`,
  на странице fetch и `ReadableStream`.
- Инструменты глобуса - команды с `gate`. Первый набор - то, что Lite
  уже умеет: перелёт, поиск места, тело, слои каталога, время,
  прозрачность, метки KML с подтверждением, вид.
- Окно «Помощник», настройки, карточка «Разрешить?», «Объясни это»
  в карточках.

## Помощник Lite

Перенесён 26 октября 2026 года, решение автора - «сначала ядро
с тестами, потом окно и инструменты, умолчания как в Про».

- Крейт `crates/assistant` - перенос `core/assistant.py` модуля без
  сети, потоков и egui, собирается под wasm32. Тесты модуля перенесены
  все (`test_assistant`, `test_assistant_agent`). Для Lite - свои
  `lite_tools` и `lite_system_text`: без руководства (`search_docs`,
  `read_doc`) и слоёв проекта QGIS (`list_project_layers`,
  `read_features`), их у Lite нет.
- Окно `ui::ai`: разговор, «Настройки помощника», вопрос о разрешении,
  «Продолжить», предложение KML с записью в «Мои метки», «Создать
  метки» одним запросом. Подключения, адреса и модели по умолчанию -
  как у модуля, по умолчанию OpenRouter с `openrouter/free`. Ключ -
  открытым текстом в настройках программы, как ключ модуля с флажком
  «Хранить ключ без мастер-пароля». На странице настройки - в хранилище
  браузера.
- Инструменты исполняет окно глобуса (`LiteApp::ai_tool`). Ответы для
  модели - по-русски, как описания инструментов. Свою подложку по адресу
  помощник у Lite не ставит, только готовые источники.
- Строка «Поиск»: просьба словами, запрос вне Земли и место, которое
  Nominatim не нашёл, уходят помощнику, ответ - под строкой. Кнопка ✦
  у строки и Ctrl+Enter - создание меток, правая кнопка - разговор
  и настройки. «Объясни это» - в карточке метки.
- Сеть: `net::Request::keep_error_bodies` - ответ с ошибкой HTTP
  приходит с телом, причина отказа сервиса видна. Ответ ждётся до 300 с.
  Потока ответа у Lite пока нет, «Создать метки» ждёт документ целиком.
- Проверка - тесты `ui::ai` с поддельным сервером модели: круг с вызовом
  инструмента, без ключа, создание меток, ошибка HTTP с телом. Живые
  запросы к сервисам не проверялись - ключ вводит автор.

## Сервер MCP Lite

Сделан 27 октября 2026 года по образцу RustGIS, решение автора -
«ядро, ретранслятор в программе, planetx-lite mcp для stdio, снимок
вида».

- `assistant::mcp` - сервер без ввода-вывода: `initialize` с выбором
  версии (2025-06-18, 2025-03-26, 2024-11-05), `ping`, `tools/list`,
  `tools/call`, пустые ресурсы и подсказки, пакеты до 16 сообщений.
  Инструменты - инструменты помощника Lite и `snapshot`. Вызовы,
  на которые помощник спрашивает разрешение, агенту закрыты. Ошибка
  инструмента - ответ с `isError`. Тесты `assistant/tests/mcp.rs`.
- `ui::mcprelay` - ретранслятор в программе. Выключен, пока в
  «Настройках помощника» не стоит «Пускать агентов MCP» или программа
  не запущена с `--mcp` (на один запуск, в настройки не пишется).
  Слушает только 127.0.0.1:8770 (`PLANETX_MCP_PORT`), ключ - в файле
  `mcp-8770.token` папки программы, первая строка соединения -
  `planetx/attach` с ключом за 5 с. Сообщения идут в кадр окна по
  одному, ответ ждётся до 120 с, соединений не больше 8.
- `planetx-lite mcp` - тот же исполняемый файл без окна: мост stdio
  клиента к сокету ретранслятора. Окно настроек показывает команду
  `claude mcp add` и настройку для Claude Desktop.
- `snapshot` ждёт конца перелёта и загрузки места (30 спокойных кадров,
  как `--shot`), но не дольше 10 с, снимает вид без окон, JPEG до 1280
  пикселей по стороне с точкой взгляда в подписи.
- Метки агента (`add_kml`) - предложением в окне помощника, запись
  подтверждает пользователь.
- Проверено живой сессией: программа с `--mcp`, клиент через
  `planetx-lite mcp` - рукопожатие, список инструментов, перелёт
  к Перми, сведения о точке, отказ записи облёта, снимок 1280 × 1045
  JPEG 340 КБ с 30 км, вся сессия 4 с. С Claude Code и Claude Desktop
  не проверялось.
- Нет пока MCP по HTTP, журнала вызовов и строки состояния с числом
  агентов. У страницы MCP нет: браузер не принимает соединений.

## Риски

- Ключ на странице виден расширениям браузера: строгая CSP, ключ
  по умолчанию не сохраняется, свой ключ в страницу не встраивается.
- CORS провайдеров проверяется запросом со страницы. Без CORS нужен
  посредник - сервер и решение автора.
- Стоимость: пределы шагов, вывода и токенов ответа, сжатие. Выбор
  модели по умолчанию за автором.
- Ответ модели - враждебный ввод: числа в пределах, KML своим
  разбором, адреса через проверку.
