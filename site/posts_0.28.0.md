# Аддины PlanetX Lite - как поставить и как написать свой

PlanetX Lite 0.28.0 принимает аддины. Аддин - модуль WebAssembly
в песочнице. Он добавляет свою команду в меню слоя «Моих слоёв».
Команда получает объекты слоя и отдаёт новый слой. Один и тот же аддин
работает в программе для Windows, Linux и macOS и на странице
в браузере.

## Как поставить аддин

Окно «Аддины» открывается через Поиск ▸ «Аддины».

- Вкладка «Каталог» показывает проверенные аддины хранилища
  planetx-lite-addins. Кнопка «Установить» скачивает пакет. Пакет
  ставится, только если его SHA-256 совпадает с каталогом.
- Вкладка «Установленные» выключает, обновляет и удаляет аддины.
- Кнопка «Из файла…» ставит пакет `.pxaddin` мимо каталога,
  с предупреждением. Открытый или брошенный в окно пакет ведёт к тому
  же окну.

Перед установкой окно показывает автора, лицензию и права аддина.
У аддина нет файлов, сети и часов. Каждый вызов ограничен по шагам
и памяти, бесконечный цикл кончается ошибкой.

Первый аддин каталога - «Буфер». Он строит полигон на заданном
расстоянии вокруг точки, линии или полигона, у полигона и внутрь.
Объект переводится в местную азимутальную равнопромежуточную проекцию
с центром в нём, поэтому буфер верен у полюсов и через 180-й меридиан.

Порядок работы такой.

1. В «Мои слои» открывается слой - GeoPackage, Shapefile, GeoJSON,
   GPX, MapInfo, FlatGeobuf или DXF.
2. Нужные объекты выделяются. Без выделения команда идёт над всеми
   объектами слоя.
3. Меню «⋯» строки слоя - «Буфер…». Окно параметров показывает слой
   и количество объектов, расстояние задаётся в метрах.
4. Кнопка «Выполнить» кладёт новый слой «Дороги · Буфер 100 м».

## Как написать свой аддин

Аддин пишется на Rust с крейтом `addin-api` из PlanetX Lite. Крейт
читает запрос и пишет результат. Окно параметров Lite рисует сама,
по описанию аддина.

1. Инструменты - Rust и цель WebAssembly
   `rustup target add wasm32-unknown-unknown`, Python 3 для упаковки.
2. Новый крейт `cargo new --lib mean-point`. В `Cargo.toml` -
   `crate-type = ["cdylib", "rlib"]` и зависимость `addin-api` из
   хранилища Lite с меткой `v0.28.0`.
3. Описание `addin.json` - id, версия, автор, лицензия, название
   на двух языках, права `features` и `layers`, команды. У команды
   есть параметры четырёх видов - число с единицей и пределами, текст,
   флажок и выбор из вариантов.
4. Модуль экспортирует пять функций - `pxa_abi`, `pxa_manifest`,
   `pxa_input`, `pxa_command` и `pxa_output`. Это около 40 строк,
   их можно взять из руководства без изменений.
5. Сама команда - обычная функция Rust. Она получает имя команды,
   параметры JSON и объекты, отдаёт новые объекты. Вершина объекта -
   широта, долгота и высота в WGS84.
6. Тест функции идёт без WebAssembly. Тест собранного модуля идёт
   в той же песочнице, что в Lite, крейт `addin-host`.
7. Сборка `cargo build --release --target wasm32-unknown-unknown`
   даёт модуль около 90 КБ. Скрипт `pack.py` каталога упаковывает его
   с описанием в `.pxaddin`.
8. Пакет пробуется в Lite кнопкой «Из файла…».

Публикация - выпуск пакета в своём хранилище и запрос на слияние
в каталог. Запрос добавляет запись с адресом пакета и его SHA-256.
Сборка каталога скачивает пакет и сверяет SHA-256, id, версию и права.
После слияния аддин виден на вкладке «Каталог» у всех.
