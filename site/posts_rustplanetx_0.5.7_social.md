# RustPlanetX 0.5.7 - тексты для площадок

## RU - Telegram, ВК, Facebook

RustPlanetX 0.5.7 - трёхмерный глобус PlanetX для RustGIS. Рельеф глобуса теперь с отмывкой в каждом пикселе, впадины и ущелья затенены.

Силу отмывки и азимут света задают «Отмывка» и «Азимут света» в «Свойствах вида», группа «Рельеф». Одиночные выбросы высот Terrarium убираются при чтении тайла, пиков и полос на сетке рельефа больше нет.

Внутри - PlanetX Lite 0.28.0.

Установка в RustGIS 0.5.0 и новее - «Plugins › Plugin Manager › Settings › Install From File…», файл rustplanetx-0.5.7.rgplugin. Пакет для Windows.

Выпуск - https://github.com/Valery35/rustplanetx/releases/tag/v0.5.7

## EN - LinkedIn

RustPlanetX 0.5.7 - the PlanetX 3D globe for RustGIS. The globe's relief now has per-pixel hillshading, valleys and gorges are shaded.

Shading and Light azimuth in View properties, group Relief, set the strength of the shading and the direction of the light. Single height spikes of Terrarium are removed when a tile is read, so the relief has no more spikes and stripes.

Inside is PlanetX Lite 0.28.0.

Install in RustGIS 0.5.0 or newer - Plugins › Plugin Manager › Settings › Install From File…, the file rustplanetx-0.5.7.rgplugin. The package is for Windows.

Release - https://github.com/Valery35/rustplanetx/releases/tag/v0.5.7

## OSGeo Discourse (тема 155878)

RustPlanetX 0.5.7 - the PlanetX 3D globe for RustGIS.

- Per-pixel hillshading of the relief, valleys and gorges are shaded.
- Shading (0-100 %, 50 % by default) and Light azimuth (315° by default) in View properties, group Relief.
- Single height spikes of Terrarium are removed when a tile is read, the relief has no more spikes and stripes.
- Inside is PlanetX Lite 0.28.0.
