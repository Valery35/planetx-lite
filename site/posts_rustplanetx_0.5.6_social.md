# RustPlanetX 0.5.6 - тексты для площадок

## RU - Telegram, ВК, Facebook

RustPlanetX 0.5.6 - трёхмерный глобус PlanetX для RustGIS. Слои глобуса теперь уходят в проект RustGIS так же, как модуль PlanetX кладёт их в проект QGIS.

В проект ложатся объекты и картинка вида со строк витрины, горизонтали вида, метки тремя слоями, картинки на поверхности, космоснимки, карты тренда и исторические карты Рамсея. Всё приходит группой «RustPlanetX - слои глобуса». Векторы становятся слоями, картинки - растрами GeoTIFF с прозрачностью.

Внутри - PlanetX Lite 0.27.0.

Установка в RustGIS 0.5.0 и новее - «Plugins › Plugin Manager › Settings › Install From File…», файл rustplanetx-0.5.6.rgplugin. Пакет для Windows.

Выпуск - https://github.com/Valery35/rustplanetx/releases/tag/v0.5.6

## EN - LinkedIn

RustPlanetX 0.5.6 - the PlanetX 3D globe for RustGIS. Globe layers now go to the RustGIS project, as the PlanetX plugin puts them into the QGIS project.

View objects and pictures of catalogue layers, view contours, placemarks as three layers, pictures on the surface, satellite images, trend maps and historical Rumsey maps go to the project in the group RustPlanetX - globe layers. Vectors become layers, pictures become GeoTIFF rasters with transparency.

Inside is PlanetX Lite 0.27.0.

Install in RustGIS 0.5.0 or newer - Plugins › Plugin Manager › Settings › Install From File…, the file rustplanetx-0.5.6.rgplugin. The package is for Windows.

Release - https://github.com/Valery35/rustplanetx/releases/tag/v0.5.6
