## EN - OSGeo, LinkedIn

PlanetX Lite 0.24.0 - 3D Tiles by a link, My layers as a panel section and a scene shared with the PlanetX plugin for QGIS 1.42.

A 3D Tiles set opens by a link from the search line, from a tileset.json file or a ZIP archive. Pieces load as the camera comes closer, Draco and meshopt compression is read. My layers is a panel section of its own, like the QGIS project in the plugin, and the results of the analysis windows come there. The Add data window has sections and row previews. Water mixes with the imagery as in the plugin, and low land such as the Caspian Depression stays dry. The scene follows the common format of the PlanetX line, so the plugin and Lite open it the same way.

Desktop program for Windows, Linux and macOS and the web page - https://valery35.github.io/planetx-lite/
Release - https://github.com/Valery35/planetx-lite/releases/tag/v0.24.0

Заголовок: PlanetX Lite 0.24.0 - a 3D globe in Rust and wgpu now streams 3D Tiles with Draco and meshopt

PlanetX Lite is a free (Apache 2.0) 3D globe written in Rust with egui and wgpu. The same code runs as a desktop program for Windows, Linux and macOS and as a web page through WebAssembly.

Version 0.24.0:

- **3D Tiles** open by a link, from a tileset.json file or a ZIP archive. Pieces load by the screen error with replacement and no holes, Draco is read by draco-core and meshopt by own code.
- **My layers** became a panel section of its own, with drag-and-drop order and the results of the analysis windows.
- **Own readers** for GRIB2 weather and LAS, LAZ and COPC point clouds.
- **One scene format** with the PlanetX plugin for QGIS.

- Web page: https://valery35.github.io/planetx-lite/
- Release: https://github.com/Valery35/planetx-lite/releases/tag/v0.24.0
