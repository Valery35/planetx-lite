# AGENTS.md - рабочий контекст проекта PlanetX Lite

Файл читается первым в начале любого нового чата по проекту.
Единственный источник правды - этот файл и документы рядом с ним,
а не переписка. Изменилось что-то в постановке или в процессе - правка

2. Прочитать план `doc/PLAN.md` и документы, которых касается задача.
3. Назвать задачу и признак готовности до того, как что-то менять.

## Что это

PlanetX Lite - глобус PlanetX без QGIS. Одна программа на Rust для
Windows, Linux и macOS и та же программа страницей в браузере
(WebAssembly), на телефоне тоже. Lite показывает Землю, рельеф, снимки
и подписи, открывает сцены `.planetx` и файлы KML и KMZ, проигрывает
туры, показывает свои данные - растры, слои GeoPackage, облака точек,
3D-модели. Lite - просмотрщик и рассказчик, а не вторая копия модуля.

Заведён 21 октября 2026 года по решению автора. План фаз, устройство
и открытые решения - `doc/PLAN.md`.

## Связь с модулем PlanetX для QGIS

- Модуль - `C:\Dev\planetx`, хранилище `github.com/Valery35/planetx`,
  Python, GPL 3. Правка данных, анализ и подготовка сцен остаются

- Связь между ними - файлы, это сцена `.planetx` (ZIP с `scene.json`

- Ядро модуля без Qt и QGIS (`planetx/core`) - источник переноса
  на Rust вместе с тестами (`planetx/tests`). Тесты переносятся раньше

- Устройство движка модуля, решения и журнал найденных ошибок -
  `C:\Dev\planetx\AGENTS.md`, разделы «Устройство», «Решения, которые
  не пересматривать без обсуждения» и «Журнал решённых вопросов».
  Перед переносом части ядра читается его запись там.

## Решения, взятые из модуля

- Мировая система - ECEF на эллипсоиде WGS84 в double. В видеокарту
  мировые координаты не попадают - смещения от центра тайла и матрица
  с отсчётом от глаза.
- Тайлы - XYZ Web Mercator, уровни 0-19, юбки по краю, подстилка под
  щелями. Уровень - по экранной ошибке, порог 1.5 пикселя.
- Дыр в подложке нет по построению - тайл заменяется детьми, когда они
  готовы, на месте неготового потомка рисуется предок.
- Камера задаётся позой - точка взгляда, расстояние, азимут, наклон.
  Перелёт - метод van Wijk-Nuij.
- Сеть не блокирует главный поток. Запрос OSM несёт заголовок
  `User-Agent` программы с адресом хранилища, к `tile.openstreetmap.org`
  не больше двух запросов сразу, подпись источников стоит на экране.
- Критерий частоты кадров - не меньше 55 кадров в любом окне 1 с над
  загруженным местом.

## Образец устройства - RustGIS

RustGIS (`github.com/opengeos/RustGIS`, Qiusheng Wu, Apache 2.0) -
образец устройства, правил и сборки. Его библиотеки в зависимости
не берутся. Чтение форматов - terrio того же автора (крейт `terrio`,
MIT), 21 октября 2026 года проверен на данных модуля и сверен с GDAL -
`doc/PLAN.md`, раздел «Проверка terrio».

## Аддины

Начальная установка лёгкая. Данные и функции добавляются аддинами,
их смогут писать и сторонние авторы. Аддин - модуль WebAssembly
в песочнице с узким версионированным API, решение автора от 21 октября
2026 года. Устройство - `doc/PLAN.md`, раздел «Аддины».

## Правила кода

- Рабочее пространство Cargo - библиотеки в `crates`, приложения
  в `apps`. Слои библиотек - в `doc/PLAN.md`, нижний слой не зависит
  от верхнего, интерфейс - только верхний слой.
- Всё ниже `apps` собирается и под `wasm32-unknown-unknown`. Время -
  `web_time`, а не `std::time`.
- Нет `unsafe`, `unwrap`, `expect`, `panic!`, `todo!` в рабочем коде.
  Входной файл считается враждебным. Исключение, решение автора
  от 23 октября 2026 года - `#[unsafe(no_mangle)]` у экспортов
  в коде аддинов (`addins`), без него функцию из модуля WebAssembly
  не экспортировать.
- Движок аддинов - wasmi в программе и на странице, решение автора
  от 23 октября 2026 года.
- Лицензия Lite - Apache 2.0, файл `LICENSE`. Зависимости только под
  разрешительными лицензиями (MIT, BSD, Apache 2.0, Zlib, ISC,
  MPL 2.0), GPL, LGPL и AGPL не берутся. Решением автора от 22 октября
  2026 года разрешены ещё BSL-1.0, OFL-1.1, Ubuntu Font 1.0,
  Unicode-3.0 и CDLA-Permissive-2.0, решением от 23 октября 2026 года -
  IJG (jpeg-encoder в terrio). Полный список - `deny.toml`,
  его проверяет CI (`cargo deny check licenses`). Новая лицензия
  в список - только с согласия автора.
- Комментарии и документация в коде - по-русски, шапка с лицензией
  в каждом файле. Правообладатель - ООО «Информ++», как в модуле.
  Шапка файла Rust:

  ```
  // PlanetX Lite - глобус PlanetX без QGIS.
  // Copyright (C) 2026 ООО «Информ++». Лицензия Apache 2.0.
  // SPDX-License-Identifier: Apache-2.0
  ```
- Тексты для пользователя - через перевод, русский и английский.
- Мировые координаты в float32 не считаются ни в ядре, ни в шейдере.
- Абсолютных порогов там, где величина зависит от масштаба, нет -
  сравнение в относительных величинах или в пикселях экрана.

## Приёмка работы

Задача имеет признак готовности, который можно проверить. Признак
называется до начала работы. «Готово» говорится только после прогона,
без прогона - «сделано, не проверялось». Разобранная ошибка получает
тест, который краснеет на прежнем поведении. Проверка соразмерна
правке - проверяется изменённое.

## Что решает автор, а не помощник

- номер версии и момент выпуска
- состав фаз и критерии их приёмки
- источники подложки и рельефа
- содержание заголовка `User-Agent`
- величины умолчаний, которые видит пользователь
- лицензия и публикация

## Что не делается без спроса

Коммит и отправка в хранилище, публикация, удаление файлов рабочей
копии, установка программ на машину автора, массовое скачивание тайлов
с чужих серверов. Готовность к такому действию сообщается, само
действие ждёт ответа. Git автор ведёт через GitHub Desktop, команды
`git` в PATH нет. Помощник берёт `git.exe` из папки GitHub Desktop
(`%LOCALAPPDATA%\GitHubDesktop\app-*\resources\app\git\cmd`).

Исключения, решения автора от 22 октября 2026 года, коммит и отправка
в `main` без спроса:
- исправления, после которых CI снова зелёный;
- шаги фазы 1 из `doc/PLAN.md`, когда их проверки прошли у помощника.

- В текстах для пользователя первого лица нет.
