PlanetX Lite 0.26.0 - JAXA Earth satellite data by month and I3S scene
layers of ArcGIS by a link. A program for Windows, Linux and macOS and
the same program as a web page:
https://valery35.github.io/planetx-lite/

- Seven JAXA Earth rows in the Add data window - land and sea surface
  temperature, the NDVI vegetation index, chlorophyll-a in the sea,
  GSMaP precipitation, soil moisture and aerosol optical depth. Each
  row is a monthly mean for the whole world on a 0.1° grid with its
  own scale. The month is set by the time slider, without it the
  latest month is shown. The data comes from the JAXA Earth cloud
  optimized GeoTIFF files.
- An I3S scene layer opens by a link to an ArcGIS SceneServer service
  or to its layer, from the search line or the command line. 3D Object
  and Integrated Mesh layers of I3S 1.7 and newer are read, with Draco
  geometry and JPEG and PNG textures. The layer goes to the Layers
  section next to the 3D Tiles sets and loads as the camera comes
  closer.
- A heavy 3D Tiles set no longer loads in a loop. The ready children
  of a shown tile stay in memory while they wait for their neighbours.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.26.0 - спутниковые данные JAXA Earth по месяцам и слои
сцен I3S сервисов ArcGIS по ссылке. Программа для Windows, Linux
и macOS и та же программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- Семь строк JAXA Earth в окне «Добавить данные» - температура
  поверхности суши и моря, вегетационный индекс NDVI, хлорофилл-а
  в море, осадки GSMaP, влажность почвы и оптическая толща аэрозоля.
  Каждая строка - среднее за месяц по всему миру на сетке 0.1° со
  своей шкалой. Месяц задаёт шкала времени, без неё виден последний
  месяц. Данные берутся из файлов COG JAXA Earth.
- Слой сцены I3S открывается по ссылке на сервис ArcGIS SceneServer
  или на его слой - из строки поиска или командной строки. Читаются
  слои 3D Object и Integrated Mesh I3S 1.7 и новее, геометрия Draco
  и текстуры JPEG и PNG. Слой встаёт в раздел «Слои» рядом с наборами
  3D Tiles и подгружается по мере приближения камеры.
- Тяжёлый набор 3D Tiles больше не грузится по кругу. Готовые дети
  показанного тайла остаются в памяти, пока ждут соседей.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
