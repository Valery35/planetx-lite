PlanetX Lite 0.13.0 - field boundaries of the world, OpenAerialMap
imagery, division of an area into objects and the search for similar
areas, as in the PlanetX plugin for QGIS. A program for Windows, Linux
and macOS and the same program as a web page:
https://valery35.github.io/planetx-lite/

- Field boundaries 2025 and 2024: rows of the map catalogue with the
  agricultural fields of the world from Fields of the World. This is a
  model estimate from Sentinel-2 imagery and not a cadastre. The colour
  is the model score, a click in Identify features mode shows it.
  Fields are seen from a height of about 70 km and lower.
- OpenAerialMap imagery: a window with the images in the view frame.
  An image lies as tiles over the base map and stays a row of the map
  catalogue. Each image has its own license, it is shown in the list
  and written to the credit of the layer. Images with NC are for
  non-commercial use only. The window works in the program, the
  OpenAerialMap search service does not answer the web page.
- Division into objects in the Classification window: the area is
  divided into objects similar in colour and texture, a class goes to
  the whole object. The result is polygons in My placemarks. The object
  scale, the texture share and the least object are set in the window.
- Similar areas: outline a sample on the globe, the program finds the
  objects of the area similar to it. The Similarity slider changes the
  selection at once, nothing is computed again.
- On the web page objects and similar areas are available when a raster
  is open.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.13.0 - границы полей мира, снимки OpenAerialMap, деление
участка на объекты и поиск похожих областей, как в модуле PlanetX для
QGIS. Программа для Windows, Linux и macOS и та же программа страницей
в браузере: https://valery35.github.io/planetx-lite/

- Границы полей 2025 и 2024: строки каталога карт с сельскохозяйственными
  полями мира из набора Fields of the World. Это оценка модели по снимкам
  Sentinel-2, а не кадастр. Цвет - оценка модели, щелчок в режиме
  «Определить объекты» её показывает. Поля видны с высоты около 70 км
  и ниже.
- Снимки OpenAerialMap: окно со снимками в рамке вида. Снимок ложится
  тайлами поверх подложки и остаётся строкой каталога карт. У каждого
  снимка своя лицензия, она показана в списке и записывается в подпись
  слоя. Снимки с NC - только для некоммерческого использования. Окно
  работает в программе, служба поиска OpenAerialMap странице не отвечает.
- Деление на объекты в окне «Классификация»: участок делится на объекты,
  похожие по цвету и текстуре, класс получает объект целиком. Итог -
  многоугольники в «Моих метках». Масштаб объектов, доля текстуры
  и наименьший объект задаются в окне.
- Похожие области: образец обводится на глобусе, программа находит
  похожие на него объекты участка. Ползунок «Похожесть» меняет выборку
  сразу, расчёт заново не идёт.
- На странице в браузере объекты и похожие области доступны при открытом
  растре.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
