PlanetX Lite 0.16.0 - a tour recorded as PNG frames, as in the PlanetX
plugin for QGIS. A program for Windows, Linux and macOS and the same
program as a web page:
https://valery35.github.io/planetx-lite/

- Tour recording: the button on the tour panel writes the tour as PNG
  frames to a folder, 25 frames per second of the tour. The size of the
  frame is the size of the view. Stop captions and source credits stay on
  the frame, the windows do not.
- Every frame waits for loading, so the frames do not depend on the speed
  of the network. The recording takes longer than the tour.
- The file `frames.json` lies next to the frames: the frame rate, the size,
  the camera pose of every frame and the list of frames not fully loaded.
- Recording works in the program. The web page has no access to folders.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.16.0 - запись тура кадрами PNG, как в модуле PlanetX для
QGIS. Программа для Windows, Linux и macOS и та же программа страницей
в браузере:
https://valery35.github.io/planetx-lite/

- Запись тура: кнопка на панели тура пишет тур кадрами PNG в папку,
  25 кадров в секунду тура. Размер кадра - размер вида. Подписи остановок
  и подписи источников входят в кадр, окна не входят.
- Каждый кадр ждёт загрузки, поэтому кадры не зависят от скорости сети.
  Запись идёт дольше тура.
- Рядом с кадрами лежит файл `frames.json`: частота, размер, поза камеры
  каждого кадра и список недогруженных кадров.
- Запись работает в программе. На странице доступа к папкам нет.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
