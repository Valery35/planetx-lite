PlanetX Lite 0.22.0 - file layers, as QGIS layers in the PlanetX plugin
for QGIS. A program for Windows, Linux and macOS and the same program as
a web page:
https://valery35.github.io/planetx-lite/

- Vector files open as rows of the "Layers" section - GeoPackage,
  Shapefile, GeoJSON, GPX, TopoJSON, GML, MapInfo, FlatGeobuf, DXF and
  DWG. A layer in another coordinate system is transformed to WGS84.
- A shapefile and a MapInfo table open with their neighbour files. On the
  page choose them or drop them into the window together.
- The menu of a layer row sets the colour, line width, fill, point size,
  opacity and the order of layers.
- "Labels" by a field and "Extrusion" by a number field - a polygon
  becomes a prism, a point a column, a line a wall.
- "Identify features" shows the fields of a layer feature. "Copy to My
  Places" puts the layer into places.
- GeoPackage now opens as a layer too.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.22.0 - слои файлов, как слои QGIS в модуле PlanetX для
QGIS. Программа для Windows, Linux и macOS и та же программа
страницей в браузере:
https://valery35.github.io/planetx-lite/

- Векторные файлы открываются строками раздела «Слои» - GeoPackage,
  Shapefile, GeoJSON, GPX, TopoJSON, GML, MapInfo, FlatGeobuf, DXF
  и DWG. Слой в другой системе координат пересчитывается в WGS84.
- Шейпфайл и таблица MapInfo открываются вместе с соседними файлами.
  На странице они выбираются или бросаются в окно вместе.
- Меню строки слоя задаёт цвет, толщину линии, заливку, размер точки,
  непрозрачность и порядок слоёв.
- «Подписи» по полю и «Выдавливание» по числовому полю - многоугольник
  становится призмой, точка столбиком, линия стенкой.
- «Определить объекты» показывает поля объекта слоя. «Копия в «Мои
  метки»» переносит слой в метки.
- GeoPackage теперь тоже открывается слоем.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
