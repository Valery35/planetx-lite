PlanetX Lite 0.28.0 - add-ins. A WebAssembly module in a sandbox adds
a command to the menu of a layer of My layers. A program for Windows,
Linux and macOS and the same program as a web page:
https://valery35.github.io/planetx-lite/

- The window Add-ins (Search ▸ Add-ins) installs, updates, turns off and
  removes add-ins. The Catalogue tab lists the checked add-ins of
  https://github.com/Valery35/planetx-lite-addins. A package from the
  catalogue is installed only when its SHA-256 equals the catalogue.
- From file… installs a `.pxaddin` past the catalogue, with a warning.
  An opened or dropped `.pxaddin` leads to the same window.
- Before installation the window shows the author, the license and the
  rights of the add-in. An add-in has no files, no network and no
  clock. It receives the objects of a command and gives new objects
  back.
- A command of an add-in is an item of the layer menu. It runs over the
  selected objects of the layer, without a selection over all of them.
  Lite draws the window of parameters by the description of the
  command. The result is a new layer.
- The first add-in of the catalogue is Buffer - a polygon at a given
  distance around a point, a line or a polygon, inward for a polygon.
  The buffer is right at the poles and across the 180th meridian.
- The guide to writing add-ins with a complete example, tests and the
  publication in the catalogue -
  https://github.com/Valery35/planetx-lite/blob/main/addins/README.md

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.28.0 - аддины. Модуль WebAssembly в песочнице
добавляет команду в меню слоя «Моих слоёв». Программа для Windows,
Linux и macOS и та же программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- Окно «Аддины» (Поиск ▸ «Аддины») ставит, обновляет, выключает
  и удаляет аддины. Вкладка «Каталог» показывает проверенные аддины
  https://github.com/Valery35/planetx-lite-addins. Пакет из каталога
  ставится, только если его SHA-256 совпадает с каталогом.
- Кнопка «Из файла…» ставит `.pxaddin` мимо каталога,
  с предупреждением. Открытый или брошенный в окно `.pxaddin` ведёт
  к тому же окну.
- Перед установкой окно показывает автора, лицензию и права аддина.
  У аддина нет файлов, сети и часов. Он получает объекты команды
  и отдаёт новые объекты.
- Команда аддина - пункт меню слоя. Она идёт над выделенными объектами
  слоя, без выделения - над всеми. Окно параметров Lite рисует
  по описанию команды. Результат - новый слой.
- Первый аддин каталога - «Буфер», полигон на заданном расстоянии
  вокруг точки, линии или полигона, у полигона и внутрь. Буфер верен
  у полюсов и через 180-й меридиан.
- Руководство, как написать аддин, с готовым примером, тестами
  и публикацией в каталоге -
  https://github.com/Valery35/planetx-lite/blob/main/addins/README.ru.md

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
