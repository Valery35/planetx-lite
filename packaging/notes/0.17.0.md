PlanetX Lite 0.17.0 - terrain analysis as in the PlanetX plugin for QGIS
1.27-1.31: the globe basemap as a source, the object pattern, minerals
by spectrum and EMIT minerals. A program for Windows, Linux and macOS and
the same program as a web page:
https://valery35.github.io/planetx-lite/

- The "Classification" and "Similar areas" windows take the globe
  basemap as a source. Pixels of 1, 2 and 5 m for rasters and the
  basemap. The object pattern - step, grain, direction and share of sharp
  edges - tells field rows from grass of the same colour.
- The "From places" button takes the area from a polygon of My Places.
- "Minerals by spectrum": the spectrum of an image pixel against 1657
  USGS references, classes of the area by the angle between spectra.
  The window finds ASTER images of the area suitable for minerals and
  loads all their bands with one button.
- "EMIT minerals": NASA mineral maps of the EMIT spectrometer, pixel 60 m.
  The list shows only suitable scenes. Files by an Earthdata key, in the
  program only.
- Analysis windows share one layer on the globe: a new result replaces
  the previous one. The classes and their shares are shown on a scale in
  the corner of the globe.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.17.0 - анализ местности, как в модуле PlanetX для QGIS
1.27-1.31: подложка глобуса как источник, рисунок объекта, минералы
по спектру и минералы EMIT. Программа для Windows, Linux и macOS и та же
программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- Окна «Классификация» и «Похожие области» берут источником подложку
  глобуса. У растров и подложки есть пиксели 1, 2 и 5 м. Рисунок
  объекта - шаг, зерно, направленность и доля резких перепадов -
  отличает ряды посевов от травы того же цвета.
- Кнопка «Из меток» берёт участок из многоугольника «Моих меток».
- «Минералы по спектру»: спектр пикселя снимка рядом с 1657 эталонами
  USGS, классы участка по углу между спектрами. Окно само находит
  подходящие для минералов снимки ASTER участка и загружает все их
  каналы одной кнопкой.
- «Минералы EMIT»: карты минералов NASA по снимкам спектрометра EMIT,
  пиксель 60 м. В списке только подходящие сцены. Файлы - по ключу
  Earthdata, только в программе.
- У окон анализа общий слой на глобусе: новый результат снимает
  прежний. Классы и их доли показывает шкала в углу глобуса.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
