PlanetX Lite 0.24.0 - 3D Tiles by a link, My layers as a panel section
and a scene shared with the PlanetX plugin for QGIS 1.42. A program for
Windows, Linux and macOS and the same program as a web page:
https://valery35.github.io/planetx-lite/

- A 3D Tiles set opens by a link from the search line or the command
  line, and from a tileset.json file or a ZIP archive. Pieces load by
  the screen error, near ones first. Draco and meshopt compression is
  read. The sets of the last launch come back to the globe at start.
- My layers is a panel section between Places and Layers, like the QGIS
  project in the plugin. The order of rows is the drawing order, rows
  move by dragging. A changed file of a layer gets the row "Reload".
  The results of the analysis windows come into My layers as a folder.
- The Add data window has the sections and the row previews of the
  plugin.
- Water mixes with the imagery as in the plugin. The water mask by the
  vector base keeps low land dry, for example the Caspian Depression.
- Folder checks in My Places follow the plugin rules.
- The scene is written by the format of the PlanetX line - the body,
  the view with the key of the base map, the time, the layers of the
  host program. Own icon pictures go into the KMZ archive.
- Labels of the base map are smaller from afar, as in the plugin.
- Weather GRIB2 and LAS, LAZ and COPC point clouds are read by own
  code.
- The desktop program links with an open RustGIS, as the plugin links
  with a QGIS project. The layers of the RustGIS project come as a
  panel section, the view of the map and the globe follows both ways.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.24.0 - 3D Tiles по ссылке, «Мои слои» разделом панели
и общая сцена с модулем PlanetX для QGIS 1.42. Программа для Windows,
Linux и macOS и та же программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- Набор 3D Tiles открывается по ссылке из строки поиска или командной
  строки, из файла tileset.json или архива ZIP. Куски грузятся по
  экранной ошибке, ближние первыми. Сжатие Draco и meshopt читается.
  Наборы прошлого запуска встают на глобус при запуске.
- «Мои слои» - раздел панели между «Метками» и «Слоями», как «Проект
  QGIS» в модуле. Порядок строк - порядок отрисовки, строки
  перетаскиваются мышью. Изменённый файл слоя получает строку
  «Обновить». Результаты окон анализа ложатся в «Мои слои» папкой.
- Окно «Добавить данные» получило разделы и превью строк, как в модуле.
- Вода смешивается со снимком, как в модуле. Маска воды по векторной
  основе оставляет низкую сушу сухой, например Прикаспийскую
  низменность.
- Флажки папок «Моих меток» - по правилам модуля.
- Сцена пишется по формату линейки PlanetX - тело, вид с ключом
  основы, время, слои программы-хозяина. Свои картинки значков уходят
  в архив KMZ.
- Подписи основы издалека мельче, как в модуле.
- Погода GRIB2 и облака точек LAS, LAZ и COPC читаются своим кодом.
- Программа связывается с открытым RustGIS, как модуль с проектом QGIS.
  Слои проекта RustGIS приходят разделом панели, вид карты и глобуса
  следует в обе стороны.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
