PlanetX Lite 0.18.0 - tracing as in the PlanetX plugin for QGIS 1.32.
A program for Windows, Linux and macOS and the same program as a web
page:
https://valery35.github.io/planetx-lite/

- The "Tracing" window in the "Site analysis" menu turns an image of
  the area into colour areas. The source is the globe basemap or an
  open raster. Fields - number of colours, image smoothing, smallest
  area and corner rounding.
- Small areas merge with their neighbours. Borders are smoothed by the
  Potrace rule, neighbouring areas share one border.
- "OK" puts the area polygons as a folder into My Places. Each polygon
  has the fields cls, color and area_ha and is filled with its colour.
- The calculation runs in steps between frames, the window does not
  freeze.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.18.0 - трассировка, как в модуле PlanetX для QGIS 1.32.
Программа для Windows, Linux и macOS и та же программа страницей
в браузере:
https://valery35.github.io/planetx-lite/

- Окно «Трассировка» в меню «Анализ участка» раскладывает снимок
  участка на цветные области. Источник - подложка глобуса или открытый
  растр. Поля - количество цветов, сглаживание снимка, наименьшая
  область и скругление углов.
- Мелкие области сливаются с соседями. Границы сглаживаются по правилу
  Potrace, у соседних областей граница общая.
- «OK» кладёт многоугольники областей папкой в «Мои метки». У каждого
  есть поля cls, color и area_ha, заливка - цвет области.
- Расчёт идёт шагами между кадрами, окно не замирает.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
