PlanetX Lite 0.20.0 - recognition and map-like labels, as in the PlanetX
plugin for QGIS 1.38. A program for Windows, Linux and macOS and the same
program as a web page:
https://valery35.github.io/planetx-lite/

- The "Recognition" window in the "Area analysis" menu divides the area
  into classes by a summer Sentinel-2 image and an image with snow of
  March or April. Classes are set by points or by outlined sample areas.
  The window picks and loads the images itself on "Build", when the area
  and the samples are set. An opened raster of the right month is taken
  without loading.
- On snow conifers are dark and bare broadleaf forest is light, so the
  snow image tells conifers from broadleaf. Without a clear snow image
  the classes are computed by the summer one.
- Labels of the vector basemap look like map labels - a soft shadow
  instead of an outline, a large city is larger, city districts are in
  capitals with spacing. Rivers are labelled along the course, a long
  river is labelled before its tributaries. There are fewer small labels,
  only residential districts are labelled.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.20.0 - распознавание и подписи как у карт, как в модуле
PlanetX для QGIS 1.38. Программа для Windows, Linux и macOS и та же
программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- Окно «Распознавание» в меню «Анализ участка» делит участок на классы
  по летнему снимку Sentinel-2 и снимку со снегом марта или апреля.
  Классы задаются точками или обведёнными областями-образцами. Снимки
  окно подбирает и загружает само по «Построить», когда участок и образцы
  уже заданы. Открытый растр нужного месяца берётся без загрузки.
- На снегу хвоя тёмная, голый лиственный лес светлый, поэтому снимок со
  снегом отделяет хвою от листвы. Без чистого снимка со снегом классы
  считаются по летнему.
- Подписи векторной основы похожи на подписи карт - мягкая тень вместо
  обводки, крупный город крупнее, районы города прописными буквами
  с разрядкой. Реки подписаны вдоль русла, длинная река подписывается
  раньше притоков. Мелких подписей меньше, районы подписываются только
  жилые.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
