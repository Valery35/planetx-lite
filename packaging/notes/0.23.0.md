PlanetX Lite 0.23.0 - My layers and one Recognition window, as in the
PlanetX plugin for QGIS 1.40. A program for Windows, Linux and macOS and
the same program as a web page:
https://valery35.github.io/planetx-lite/

- My layers stay between launches, like My Places. The objects of a
  layer are kept in the data folder of the program, the source file is
  not needed after opening. The web page keeps layers up to 1 MB.
- Layers gather in folders of one level. The check of a folder shows or
  hides all its layers, a click on the name folds the folder.
- "Save as GeoJSON" writes the objects of a layer with all fields.
- One Recognition window instead of Classification, Object extraction,
  Tracing and Similar areas. The Task list - own samples, image colours,
  similar to the sample, forests and clearcuts, fields, water, overgrown
  fields. The source of own samples - Sentinel-2 images of the area, the
  globe basemap, an opened raster or AlphaEarth.
- The "Visible" check of a class hides it from the globe, the "Show on
  the globe" check removes the whole preview.
- "OK" puts the smoothed polygons of the classes and the lines into My
  layers, drawn in the colours of the classes.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.23.0 - «Мои слои» и одно окно «Распознавание», как
в модуле PlanetX для QGIS 1.40. Программа для Windows, Linux и macOS и та
же программа страницей в браузере:
https://valery35.github.io/planetx-lite/

- «Мои слои» сохраняются между запусками, как «Мои метки». Объекты слоя
  лежат в папке данных программы, исходный файл после открытия не нужен.
  Страница хранит слои до 1 МБ.
- Слои собираются в папки одного уровня. Флажок папки показывает или
  прячет все её слои, щелчок по названию сворачивает папку.
- «Сохранить как GeoJSON» записывает объекты слоя со всеми полями.
- Одно окно «Распознавание» вместо «Классификации», «Выделения
  объектов», «Трассировки» и «Похожих областей». Список «Задача» - свои
  образцы, цвета снимка, похожие на образец, леса и рубки, поля, вода,
  заросшие поля. Источник своих образцов - снимки Sentinel-2 участка,
  подложка глобуса, открытый растр или AlphaEarth.
- Флажок «Видно» прячет класс с глобуса, флажок «Показывать на глобусе»
  снимает весь предпросмотр.
- «OK» кладёт сглаженные многоугольники классов и линии в «Мои слои»,
  цветами классов.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
