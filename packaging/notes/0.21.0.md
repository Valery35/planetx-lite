PlanetX Lite 0.21.0 - recognition by task, as in the PlanetX plugin for
QGIS 1.39. A program for Windows, Linux and macOS and the same program as
a web page:
https://valery35.github.io/planetx-lite/

- The "Task" list of the "Recognition" window - "Forests and clearcuts",
  "Fields" and "Water". The task sets up its classes itself and computes
  them by rules from the summer and snow images, no samples are needed.
- If a class lies wrong, put its sample as a point or an outline, and
  "Build" computes again with it.
- "No image" of a row of the "Images" table holds until another image is
  chosen.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.21.0 - распознавание по задаче, как в модуле PlanetX для
QGIS 1.39. Программа для Windows, Linux и macOS и та же программа
страницей в браузере:
https://valery35.github.io/planetx-lite/

- Список «Задача» окна «Распознавание» - «Леса и рубки», «Поля» и «Вода».
  Задача сама заводит свои классы и считает их правилами по снимкам лета
  и снега, образцы не нужны.
- Если класс лёг неверно, ему ставится образец точкой или контуром,
  и «Построить» считает заново с ним.
- «Без снимка» у строки таблицы «Снимки» держится, пока не выбран другой
  снимок.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
