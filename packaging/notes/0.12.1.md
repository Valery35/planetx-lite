PlanetX Lite 0.12.1 - a raster with several bands no longer replaces
the terrain.
A program for Windows, Linux and macOS and the same program as a web
page: https://valery35.github.io/planetx-lite/

- A GeoTIFF with two or more bands opens as a source of the
  Classification window, the terrain stays as it was. The camera flies
  to the raster, the message names the number of its bands. A raster
  with one band opens as own terrain, as before.
- On the web page the Classification item appears for such a raster
  too.

The files are not signed. The system warns about every program from
an unknown publisher, this is not a sign of a virus. On Windows choose
"More info" - "Run anyway". On macOS open System Settings - Privacy &
Security - "Open Anyway". Checksums are in `SHA256SUMS`.

PlanetX Lite 0.12.1 - растр с несколькими каналами больше не подменяет
рельеф.
Программа для Windows, Linux и macOS и та же программа страницей
в браузере: https://valery35.github.io/planetx-lite/

- GeoTIFF с двумя и более каналами открывается как источник окна
  «Классификация», рельеф остаётся прежним. Камера летит к растру,
  сообщение называет количество каналов. Растр с одним каналом
  открывается своим рельефом, как раньше.
- На странице в браузере пункт «Классификация…» появляется и для
  такого растра.

Файлы не подписаны. Система предупреждает о любой программе
неизвестного издателя, это не признак вируса. Windows покажет
«Система Windows защитила ваш компьютер»: «Подробнее» - «Выполнить
в любом случае». macOS не откроет программу с первого раза:
«Системные настройки» - «Конфиденциальность и безопасность» - «Всё
равно открыть». Проверка файлов - `SHA256SUMS`.
